# WS2811_4_Digit_Clock
## 💻 Software & Libraries

This project relies on the following open-source Arduino libraries:

1. **[Adafruit NeoPixel](https://github.com/adafruit/Adafruit_NeoPixel)** – Controls the WS2812B LED strip.
2. **[RTClib by Adafruit](https://github.com/adafruit/RTClib)** – Handles communication with the RTC chip via I2C.

### Installation Steps

1. Open **Arduino IDE**.
2. Go to **Sketch** > **Include Library** > **Manage Libraries...**
3. Search for **Adafruit NeoPixel** and click **Install**.
4. Search for **RTClib** and click **Install**.
